# reims-vGPU GUI

A simple GUI for setting up and running [reims-vGPU](https://github.com/steelbrain/reims-vgpu) on Linux.

[reims-vGPU GUI](docs/picture/screenshot.png)

## Download

Download the latest version from the [Releases](../../releases) page.

After downloading:

```bash
chmod +x reims-vgpu-gui
./reims-vgpu-gui
```

## Run from source

Clone the repo:
```bash
git clone https://github.com/YOUR_USERNAME/reims-vgpu-gui.git
cd reims-vgpu-gui
```

Run:
```bash
cargo run
```
